# Task Manager

## 📖 Description
Task Manager is a console-based Python application for managing tasks.  
It allows users to add, delete, and view tasks through a simple interactive menu.

This project was created for educational purposes to practice working with file handling, data structures, and basic object-oriented programming.

---

## ⚙️ Features
- Add new tasks
- View all tasks
- Delete tasks
- Save data to a JSON file
- Simple console menu interface

---

## 🛠️ Technologies
- Python 3
- JSON (for data storage)
